# Security Policy

## Reporting Vulnerabilities

Astraguard takes security seriously. If you discover a vulnerability in the Astraguard extension, badge widget, or dashboard frontend, please report it responsibly.

### Disclosure Channels
- **GitHub Security Advisories**: Submit a report directly via [GitHub Security Advisories](https://github.com/Astraguard/Frontend/security/advisories/new)
- **Email**: `security@astraguard.io`

### Response Process
- **Initial Response**: Within 48 hours.
- **Status Updates**: Every 5 business days until resolution.
- **Public Disclosure**: Coordinated after a fix is deployed.

### Scope
- **In Scope**: `Astraguard/Frontend` extension, page hooks, badge widgets, and user dashboard.
- **Out of Scope**: Third-party wallet extensions (Freighter, Albedo) except for integration safety wrappers.
